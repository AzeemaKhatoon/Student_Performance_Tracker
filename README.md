# 🎓 Student Performance Tracker

This project is a **Machine Learning & Python-based application** that predicts and tracks student performance.  
It provides insights into how different factors affect academic results and helps in better understanding student outcomes.  

---

## 📂 Project Structure
- `Student_Performance_Application.ipynb` → Jupyter notebook for data analysis & model training  
- `Student_app.py` → Python application (main script for running the tracker)  
- `Student_performance_model.joblib` → Trained ML model  
- `scaler.joblib` → Scaler used for preprocessing  
- `Background_image.jpg` → UI background image  
- `requirements.txt` → Dependencies for running the project
